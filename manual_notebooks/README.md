# Работа с моделями в ручных ноутбуках

Открывайте `models_training.ipynb` из этого каталога в Python-окружении с
Ultralytics, NumPy, pandas, PyYAML, Pillow, IPython и matplotlib. В окружении
проекта `.venv` установлен Ultralytics 8.4.191; эта версия использовалась для
проверки предсказаний на CPU. Окружение `.venv-notebooks` позволяет запускать
автономные тесты, но Ultralytics в нём пока не установлен. Установка других
провайдеров не требуется.

## Выбор моделей и реестр

`common.MODELS` — единственный словарь булевых флагов выбора моделей.
Модели `yolov8n` и `yolo26n` включены. `common.MODELS_REGESTRY` описывает
реализации с теми же ключами; такое написание имени сохранено намеренно.
Метаданные находятся в `scripts/registry.py`.

Перед запуском семейства нужно указать конкретный файл весов. Например:

```python
from dataclasses import replace
import scripts.common as cmn

cmn.MODELS_REGESTRY["rt-detr"] = replace(
    cmn.MODELS_REGESTRY["rt-detr"], checkpoint="rtdetr-l.pt"
)
cmn.MODELS["rt-detr"] = True
```

В реестре задаётся точное имя файла весов исходного проекта.
Например, идентификатору `yolov12n` соответствует `yolo12n.pt`.
Исходные веса сохраняют имя файла провайдера, а копии обученных весов
для удобной загрузки используют `<local-model-id>.pt`.

Имена бэкендов MMDetection и RF-DETR зарезервированы, но их реализации пока нет.
Модели из других репозиториев отключены и снабжены комментариями. Проверка
наличия весов доступна без импорта Ultralytics. До начала скачивания проверяется
весь список: неподдерживаемые модели и семейства без конкретного варианта
вызывают понятную ошибку.

## Обучение и предсказание

В ноутбуке приведён пример обучения на пять эпох. Он отключён до установки
`RUN_TRAINING=True`. Включённые модели обучаются последовательно. Записи,
поддерживающие только предсказание, недоступные реализации и семейства без
варианта пропускаются с указанием причины. Некорректный датасет или непредвиденная
ошибка обучения останавливают выполнение; завершённые запуски остаются на диске.

`DatasetSpec` задаёт YAML датасета YOLO и задачу (`detect` или `segment`).
Проверку файлов, выборок и разметки выполняет Ultralytics при обучении. Текущий датасет содержит разметку для детекции; для сегментации нужны
полигоны. Пути разрешаются по правилам Ultralytics: предпочтительны абсолютный
путь к датасету и абсолютные пути в файлах выборок. Пути с `./` отсчитываются
от каталога файла выборки.

Каждый запуск сохраняет лучшие и последние веса и файл `manifest.json`.
Он содержит метаданные модели, хеш исходных весов, версию Ultralytics,
заданные и фактические настройки, путь к YAML и задачу датасета, а также метрики.
Для загрузки конкретного эксперимента используйте `run.best_artifacts`;
`weights/trained/<id>.pt` — удобная копия весов последнего успешного запуска.

```python
from scripts.contracts import DatasetSpec, TrainConfig
from scripts.workflows import train_models, load_model

batch = train_models(DatasetSpec(cmn.DATA_YAML), TrainConfig(device="cuda:0"))
run = batch.runs["yolo26n"]
predictor = load_model(run.model_id, run.best_artifacts, device="cuda:0")
results = predictor.predict("image.jpg", imgsz=640, conf=0.25)
```

Предсказание принимает одно изображение: путь к локальному файлу, объект PIL
или массив NumPy формы H×W×3, типа uint8, с порядком каналов BGR.
Модель загружается при первом обращении и переиспользуется объектом predictor.
Результаты содержат массивы NumPy на CPU: рамки, оценки уверенности,
идентификаторы и названия классов, а при наличии — булевы маски в координатах
исходного изображения. `result.native` сохраняет исходный результат Ultralytics
и средства визуализации. Обученные веса не подменяются предобученными автоматически.

## Предсказание по подсказкам

Адаптер поддерживает текстовые подсказки YOLOWorld и YOLOE, визуальные подсказки
YOLOE, точки и рамки семейства SAM, подсказки FastSAM, а также текст и примеры
объектов SAM3. Примеры приведены в ноутбуке. Текстовые классы YOLOWorld и YOLOE
сохраняются в объекте predictor до замены. Для независимого состояния подсказок
создайте новый predictor.

Семейство SAM и FastSAM здесь поддерживают только предсказание.
Нормализованные результаты не назначают семантические классы маскам,
полученным без классификации. Текст и примеры объектов в SAM3 обрабатываются
через семантический интерфейс, точки и рамки — через интерактивный.
Сопровождение объектов на видео с сохранением состояния в этот API не входит.
Некоторые операции требуют дополнительных зависимостей Ultralytics или
отдельного разрешения на получение весов. Скачанные вручную веса поместите
по пути исходных весов, заданному в реестре.

Документация исходных интерфейсов:
[модели Ultralytics](https://docs.ultralytics.com/models/),
[YOLOE](https://docs.ultralytics.com/models/yoloe/),
[SAM3](https://docs.ultralytics.com/models/sam-3/).

## Проверка

Из корня репозитория:

```bash
.venv-notebooks/bin/python -m unittest discover -s manual_notebooks/tests -v
```

Тесты используют временные файлы и имитации провайдеров; скачивание весов,
GPU и обучение не требуются. Реальное предсказание на CPU проверено отдельно
для двух включённых моделей. Остальные конструкторы и передача подсказок
проверены с имитациями провайдеров. Полное обучение, реальное предсказание
по подсказкам и сегментация не запускались.
