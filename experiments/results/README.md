# Results Directory

Generated experiment outputs belong here. Expected final artifacts:

- `yolo/model_comparison.csv`
- `yolo/<model>/results.csv`
- `yolo/<model>/confusion_matrix.*`
- `yolo/<model>/PR_curve.*`
- `yolo/<model>/results.*`
- `mask_metrics.csv`
- clean publication figures copied or generated into `figures/publication/`

Do not manually edit metric CSVs used by the article.
